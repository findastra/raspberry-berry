# Raspberry Berry

*A pet app by Astra.*

Raspberry Berry is a pet app with a raspberry logo. Its pet is named Raspberry Pi.

**Status: hatching.** This repo is a placeholder. It has a logo and one page, nothing more.

## How to run it

Open `index.html` in any modern browser. There are no dependencies and no build step.

## Logo

`logo.svg` is a simple drawn raspberry. It was drawn for this placeholder and is not an existing brand asset.

## Limits

- Pixel art is a first generated draft (`art/sheets/raspberry-berry-20261009.png`, converted into `sprite.json`). Not yet approved by Astra, and not yet in the Cage's roster.
- No Raspberry Pi hardware connection.
- No tests, no data storage, no desktop version.
- Not in the Cage yet. Registering it is card 008 for the Friendly Farmer in [astras-pet-apps](https://github.com/findastra/astras-pet-apps).
